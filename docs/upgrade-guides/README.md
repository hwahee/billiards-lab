# 업스트림 업데이트 가이드

이 보일러플레이트에서 출발한 저장소(다운스트림)가 업스트림의 변경을 머지한 뒤 무엇을 해야 하는지 적은 문서들입니다.
주 독자는 다운스트림에서 일하는 AI 에이전트입니다.

## 다운스트림에서 쓰는 법

1. 업스트림을 머지한 뒤, 아래 목록에서 **아직 적용하지 않은 가이드를 오래된 것부터** 엽니다.
   각 가이드의 "이미 적용됐는지 확인" 절로 적용 여부를 판단합니다.
2. 가이드를 위에서부터 끝까지 따릅니다. **"사람에게 확인할 결정"은 에이전트가 정하지 않습니다.**
3. 가이드의 "완료 조건"을 모두 만족하면 끝입니다.

## 업스트림에서 가이드를 쓰는 규칙

- 다운스트림이 머지만으로는 끝나지 않는 변경(스키마 마이그레이션, 배포 절차·인프라 변경, 새 코딩 규칙, 충돌이 잘 나는
  파일의 구조 변경, 제품 결정이 필요한 동작)을 머지할 때 가이드를 하나 추가합니다.
- 파일 이름은 `YYYY-MM-주제.md`이고, 아래 목록에 한 줄을 더합니다.
- 담을 것: 포함 PR과 머지 순서, 적용 여부 확인 방법, 충돌 해결 원칙, 사람에게 확인할 결정, PR별 조치와 검증 명령,
  완료 조건, 되돌리기.
